## 3. 引用與查證紀錄格式

每次確認來源時，保存這些欄位；未核對的欄位留「待核對」，不填推測值。

| 欄位 | 內容 |
|---|---|
| ID／主張 | 精確句子及預定用處 |
| 原始來源 | 機構、頁面／報告名、直接網址；轉載另記 |
| 時間 | 資料期間、發布時間、實際查閱日期 |
| 定義 | 分母、單位、幣別、涵蓋地區、買家／賣家／全部受害者 |
| 可查證內容 | 精簡原文定位或摘要；避免整份複製 |
| 界限 | 不能支持的推論、不同來源的定義差異 |
| 狀態 | 待驗證／會議已核對且本輪未重查／本輪已核對／不可用 |
| 查證者與版本 | 查證人、必要的版本或頁碼；修改哪些文案 |

公開引用須連到支持該句的原始頁面；影片來源註記也需期間與機構。若網頁改動、無法讀取或定義不符，拿掉句子，不能以印象補數字。必要的私人研究記錄只放 `data/private/sources/`；訪談逐字稿、聯絡方式、同意書與未發布商業資料一律留在 `data/private/`，不能放此公開文件。
